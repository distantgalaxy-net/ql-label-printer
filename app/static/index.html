                  Welcome! Set up your printer to get started. Check the time zone below, then tap Test and save: it checks it can reach the printer, then unlocks the label pages.

                  Printer

                  Where to send labels. The printer needs a fixed IP address (set a DHCP reservation in your router) and must accept raw printing on the port below. Only the 62mm continuous roll (DK-22205) is supported.

                  Brother printers use port 9100. If printing is refused, turn Editor Lite off on the printer. If a firewall sits between them, allow the machine running this service (e.g. your NAS) to reach the printer on this port.

                  Printer status

                  Asks the printer whether it's ready and which roll is loaded (nothing is printed). The details show exactly what the printer replied.
